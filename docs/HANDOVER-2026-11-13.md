## 8. Jebakan teknis yang sudah diketahui

- Fixture esbuild: boundary mock wajib `resolveDir: root` **dan** daftar export lengkap sesuai import komponen nyata (`getCurrentUserAction` terlewat → build gagal; sudah difix).
- Klik label switch yang `disabled` saat saving membutuhkan `click({ force: true })` di test (perilaku app benar: kunci simpan).
- Cold-start dev server bisa membuat hydration `/login` > 10 s → timeout mount fixture; warm-up dulu sebelum run.
- Warning cross-origin `127.0.0.1` vs `localhost` di dev log = tidak berbahaya.
- `report_reviews` tidak punya kolom status selain decision; status tampilan riwayat memakai `review_status` di `daily_reports` (terpisah dari submission) — sudah benar, jangan "disatukan".
- Data lama `account_requests`: kolom baru NULL = belum tercatat, **bukan** consent tersirat; jangan backfill.
